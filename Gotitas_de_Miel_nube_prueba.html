Copia de seguridad

Exportá tus materiales, productos, presupuestos y pedidos a un archivo JSON para guardar una copia. Si cambiás de computadora o navegador, podés importar esa copia.

La app guarda una copia local y sincroniza con Supabase cuando iniciás sesión. Exportá copias de seguridad regularmente.

Cómo usarla

  1. Cargá tus materiales con el precio de compra y la cantidad del paquete.
  2. Creá productos y agregá el consumo de cada material por unidad.
  3. Indicá el tiempo de trabajo y cuánto vale tu hora.
  4. Armá presupuestos con productos y cantidades.
  5. Usá “Imprimir / guardar PDF” para obtener una versión para el cliente.

Esta es una primera versión local. No tiene cuentas de usuario ni sincronización entre dispositivos. Para usarla en varios equipos o protegerla con inicio de sesión, habría que agregar una base de datos y autenticación.
